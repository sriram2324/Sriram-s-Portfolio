# Reports & Evaluation Directory

This directory stores evaluation metrics, confusion matrices, audit logs, and project reports generated during training, testing, and evaluation.

## Artifacts
- `metrics.json`: Detailed held-out test evaluation scores (accuracy, macro F1, per-class precision/recall/F1/support, confusion matrix).
- `PROJECT_REPORT.md`: Comprehensive engineering blueprint, methodology, and design document.
- `TEST_REPORT.md`: Automated testing summary, verification logs, and environment details.
