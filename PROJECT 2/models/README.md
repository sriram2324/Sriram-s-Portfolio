# Model Artifacts Directory

This directory stores the serialized scikit-learn pipeline and training metadata produced by `train.py` or `scripts/train_model.py`.

## Expected Files
- `sentiment_pipeline.joblib`: The fitted scikit-learn `Pipeline` (containing `TfidfVectorizer` and `LogisticRegression`).
- `metadata.json`: Machine-readable metadata capturing model hyperparameters, training dataset fingerprint, timestamp, class names, test set metrics, and environment versions.

## Security Notice
In accordance with safe ML engineering principles:
- Only model artifacts generated by this project should be loaded.
- The application will **never** deserialize arbitrary user-uploaded pickle or joblib files.
- If the model artifact is missing, the application clearly notifies the user and provides a training trigger.
